
## 🚀 C언어로 구현할 리눅스 명령어 30가지 개요

###  파일 및 디렉토리 기본 관리 (1~5)

*  1. `pwd`: 현재 작업 중인 디렉토리의 절대 경로 출력 (`getcwd` 사용)
*  2. `cd`: 작업 디렉토리 이동 (`chdir` 시스템 콜 활용, 내장 명령어로 처리)
*  3. `ls`: 디렉토리 내부 파일 및 폴더 목록 나열 (`opendir`, `readdir` 활용)
*  4. `mkdir`: 새로운 디렉토리 생성 (`mkdir` 시스템 콜 활용)
*  5. `rmdir`: 비어 있는 디렉토리 삭제 (`rmdir` 시스템 콜 활용)

###  파일 조작 및 텍스트 출력 (6~10)

*  6. `touch`: 빈 파일 생성 또는 파일의 수정 시간 업데이트 (`open`, `utime` 활용)
*  7. `cat`: 파일 내용을 읽어서 표준 출력으로 그대로 화면에 출력 (`fopen`, `fread` 등)
*  8. `echo`: 사용자가 입력한 문자열이나 환경 변수를 화면에 그대로 출력
*  9. `cp`: 원본 파일을 복사하여 새로운 파일 생성 (`read`/`write` 버퍼 루프)
*  10. `rm`: 파일 삭제 (`unlink` 시스템 콜 활용)

###  파일 이동 및 정보 조회 (11~15)

*  11. `mv`: 파일의 이름을 바꾸거나 다른 디렉토리로 이동 (`rename` 시스템 콜)
*  12. `ln`: 하드 링크 또는 심볼릭 링크 생성 (`link`, `symlink` 시스템 콜)
*  13. `wc`: 파일의 라인 수, 단어 수, 바이트(글자) 수 계산 및 출력
*  14. `head`: 파일의 앞부분 10줄(또는 지정한 줄 수)만 출력
*  15. `tail`: 파일의 뒷부분 10줄(또는 지정한 줄 수)만 출력

###  고급 파일 제어 및 검색 (16~20)

*  16. `chmod`: 파일이나 디렉토리의 접근 권한 변경 (`chmod` 시스템 콜)
*  17. `stat`: 파일의 상세 정보(크기, 권한, 생성 시간, i-node 등) 출력 (`stat` 구조체)
*  18. `grep`: 파일 내에서 특정 문자열 패턴을 찾아 해당 라인 출력 (`strstr` 활용)
*  19. `clear`: 터미널 화면을 깨끗하게 비움 (ANSI 이스케이프 시퀀스 활용)
*  20. `whoami`: 현재 로그인된 사용자의 이름 출력 (`getuid`, `getpwuid` 활용)

###  시스템 정보 및 리소스 확인 (21~25)

*  21. `hostname`: 현재 시스템의 호스트 이름 조회 (`gethostname` 사용)
*  22. `date`: 현재 시스템의 날짜와 시간을 포맷팅하여 출력 (`time`, `localtime`)
*  23. `uptime`: 시스템이 켜져 있었던 시간과 부하율 출력 (`/proc/uptime` 또는 `sysinfo`)
*  24. `free`: 시스템의 전체/사용 중인 메모리 정보 출력 (`/proc/meminfo` 파싱)
*  25. `sleep`: 지정된 초(second) 동안 프로그램 실행을 일시 중단 (`sleep` 시스템 콜)

###  프로세스 및 고급 시스템 제어 (26~30)

*  26. `ps`: 현재 실행 중인 프로세스 목록 출력 (`/proc/[PID]` 디렉토리 탐색)
*  27. `kill`: 특정 프로세스에 시그널을 보내 종료시킴 (`kill` 시스템 콜)
*  28. `chown`: 파일의 소유주나 소유 그룹 변경 (`chown` 시스템 콜)
*  29. `cmp`: 두 파일이 완전히 일치하는지 바이트 단위로 비교
*  30. `yes`: 사용자가 중단할 때까지 특정 문자열(기본값 y)을 무한 반복 출력
